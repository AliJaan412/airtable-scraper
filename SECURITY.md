# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please report it privately by:

1. Going to the **Security** tab of this repository
2. Clicking **"Report a vulnerability"**

Or contact the maintainer directly via GitHub: [@AliJaan412](https://github.com/AliJaan412)

### What to include in your report
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### What to expect
- Acknowledgement within **48 hours**
- A fix or mitigation plan within **7 days** for critical issues
- Credit in the release notes if you wish

Thank you for helping keep this project secure.
